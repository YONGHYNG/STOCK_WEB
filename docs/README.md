# Trading AI 문서

이 폴더는 현재 소스 코드와 `data/trading.db`를 기준으로 작성한 운영 문서다.

## 문서 목록

- [데이터베이스 구조](db/데이터베이스.md): SQLite 테이블, 컬럼, 키, 인덱스 및 저장 동작
- [투자 로직](invest/투자.md): BTCUSDT 진입·추가 진입·청산·리스크 원칙
- [프로그램 및 로직 버전](프로그램_및_로직_버전.md): 시스템 구성, 실행 프로그램, 의존성 버전
- `BTCUSDT_선물_자동매매_규칙_요약.docx`: 별도 배포용 요약 문서

## 기준일

- 문서 확인일: 2026-10-29
- 애플리케이션 버전: `0.1.0`
- 데이터베이스: SQLite `data/trading.db`

코드가 변경되면 이 문서의 가격 간격, 손절·익절 규칙, DB 컬럼과 버전 정보도 함께 갱신해야 한다.

## 문서 유지보수 원칙

프로젝트 루트의 `AGENTS.md`에 따라 다음 변경은 관련 문서를 같은 작업에서 함께 수정한다.

- 전략·진입·익절·손절·리스크 변경 → `invest/투자.md`
- DB 테이블·컬럼·인덱스·저장 방식 변경 → `db/데이터베이스.md`
- 프로그램·패키지·실행 방법·버전 변경 → `프로그램_및_로직_버전.md`
- 문서 구조 변경 → 이 `README.md`

여러 영역에 걸친 변경은 관련 문서를 모두 갱신하며, 문서의 수치와 명칭은 실제 코드 및 DB 스키마를 기준으로 검증한다.
