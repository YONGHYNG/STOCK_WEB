# 자동매매 타점 및 가격 계산

## 1. 타점이 정해지는 조건

실제 전략 판단은 1분봉 확정 캔들을 우선 사용한다.

사용 지표:

- MA90, MA200
- RSI14
- 최근 20개 캔들의 지지선
- 현재 거래량 ÷ 최근 20개 평균 거래량

### SHORT 타점

다음 중 하나를 만족하면 SHORT 후보가 된다.

#### MA 반등 실패

```text
close < MA90 < MA200
고가가 MA90 또는 MA200에 닿음
종가는 MA 아래에서 마감
이전 RSI >= 55
RSI 하락 전환
거래량 비율 >= 0.5
```

#### 지지선 이탈 후 리테스트

```text
1. 종가가 최근 20개 캔들 최저가 아래로 이탈
2. 거래량 비율 >= 0.8
3. 이탈 직후 진입하지 않고 리테스트 대기
4. 고가가 기존 지지선에 다시 닿음
5. 종가는 지지선 아래에서 마감
6. RSI < 50
```

#### 하락 추세 지속

```text
음봉 확정
close < MA90 < MA200
RSI <= 48
거래량 비율 >= 0.5
```

### LONG 타점

다음 중 하나를 만족하면 LONG 후보가 된다.

#### 최근 저점 지지 반등

```text
저가가 최근 20개 캔들 최저가에 닿음
종가는 지지선 위에서 마감
아래꼬리가 위꼬리보다 김
이전 RSI <= 40
RSI 상승 전환
거래량 비율 >= 0.5
```

#### MA 돌파 후 눌림

```text
1. 이전 종가는 MA90 아래
2. 현재 종가는 MA90과 MA200 위
3. RSI > 50
4. 거래량 비율 >= 0.8
5. 돌파 직후 진입하지 않고 눌림 대기
6. 가격이 max(MA90, MA200)까지 눌림
7. 종가는 돌파선 위로 회복
8. RSI 45~60
```

#### 상승 추세 지속

```text
양봉 확정
close > MA90 > MA200
RSI >= 52
거래량 비율 >= 0.5
```

## 2. 실제 주문 허용 조건

타점이 발생해도 다음 조건을 통과해야 실제 대기 주문을 만든다.

```text
5분봉 방향 = 진입 방향
15분봉 방향 = 진입 방향
30분봉이 반대 방향이 아님
진입 등급이 A 또는 B
예상 손실률이 설정 한도 이하
기존 포지션이 없음
재진입 대기 시간이 지남
일일·연속 손실 한도 미도달
```

추세 지속 신호는 A등급일 때만 실제 주문을 허용한다.

## 3. 지정가 계산

고정 간격 대신 5분봉 ATR과 거래량으로 지정가 간격을 계산한다.

```text
기본 간격 = 5분 ATR14 × 0.8
```

거래량 보정:

```text
5분 거래량 비율 >= 1.2 → 기본 간격 × 0.8
5분 거래량 비율 < 0.7  → 기본 간격 × 1.2
```

최종 간격 제한:

```text
최소 $100
최대 $350
```

지정가:

```text
LONG 지정가  = 기준가격 - 계산된 간격
SHORT 지정가 = 기준가격 + 계산된 간격
```

기준가격:

- 일반 LONG: 최우선 매도호가
- 일반 SHORT: 최우선 매수호가
- 지지선 이탈 SHORT: 리테스트할 기존 지지선
- MA 돌파 LONG: `max(MA90, MA200)` 돌파선

예:

```text
SHORT 기준가격 = $64,500
5분 ATR = $250
5분 거래량 비율 = 0.5

간격 = 250 × 0.8 × 1.2 = $240
SHORT 지정가 = 64,500 + 240 = $64,740
```

## 4. 손절가 계산

1분봉과 5분봉 중 큰 ATR을 사용한다.

```text
기준 ATR = max(1분 ATR14, 5분 ATR14)
손절 간격 = 기준 ATR × 3
```

손절 간격은 다음 범위로 제한한다.

```text
최소 $400
최대 $700
```

최종 손절가:

```text
LONG 손절가  = 진입가 - 손절 간격
SHORT 손절가 = 진입가 + 손절 간격
```

## 5. 익절가 계산

1차 익절 간격은 손절 간격을 기준으로 계산한다.

```text
1차 익절 간격 = 손절 간격
최소 $500
최대 $600
```

2차 익절 간격은 `$800`이다.

최종 익절가:

```text
LONG TP1  = 진입가 + 1차 익절 간격
LONG TP2  = 진입가 + $800

SHORT TP1 = 진입가 - 1차 익절 간격
SHORT TP2 = 진입가 - $800
```

## 6. 대기 주문 갱신

지정가 주문은 최대 2시간 동안 체결을 기다린다.

```text
2시간 미체결
→ 기존 주문 취소
→ 최신 타점과 지표로 진입가·손절가·익절가 재계산
→ 조건이 유효하면 새 지정가 주문 생성
```

대기 중 새로운 신호가 나오면 더 유리한 가격으로만 갱신한다.

```text
LONG  = 기존보다 낮은 진입가
SHORT = 기존보다 높은 진입가
```

## 7. 이렇게 설정한 이유

### 타점을 확정 캔들로 판단하는 이유

가격이 조건선을 순간적으로 통과했다가 되돌아오는 가짜 신호를 줄이기 위해서다. 캔들 종가, RSI, 거래량이 모두 확정된 뒤 판단하면 진입은 조금 늦어질 수 있지만 꼬리 움직임에 성급하게 진입하는 경우를 줄일 수 있다.

### 1분봉으로 타점을 잡는 이유

이 전략은 단타용이므로 실제 진입 시점은 빠른 1분봉에서 찾는다. 대신 1분봉만 사용하면 노이즈가 많기 때문에 5분·15분 방향을 함께 확인하고, 30분봉이 반대 방향일 때는 진입을 막는다.

### 거래량 조건을 사용하는 이유

MA와 RSI만으로는 거래 참여가 거의 없는 움직임에도 신호가 발생할 수 있다. 거래량 비율은 실제 매수·매도 참여가 동반됐는지 확인하는 필터다.

일반 진입은 평균의 0.5배 이상, 돌파 준비는 0.8배 이상으로 설정해 지나치게 엄격하지 않으면서 극저거래량 진입은 막도록 했다.

### 돌파 직후 바로 진입하지 않는 이유

지지선 이탈이나 MA 돌파 직후에는 가격이 다시 원래 구간으로 복귀하는 가짜 돌파가 자주 발생한다. 따라서 돌파 가격을 다시 확인하는 리테스트나 눌림이 나온 뒤 진입한다.

### 지정가 간격을 고정하지 않은 이유

고정 `$250`은 시장 변동성이 작을 때 너무 멀고, 변동성이 클 때는 너무 가까울 수 있다. ATR을 사용하면 최근 시장 움직임에 맞춰 지정가 간격이 자동으로 변한다.

거래량이 강하면 추세가 빠르게 진행될 가능성이 있으므로 간격을 줄여 체결 가능성을 높인다. 거래량이 약하면 더 좋은 가격을 기다리도록 간격을 늘린다.

최소 `$100`, 최대 `$350` 제한은 계산값이 지나치게 가깝거나 멀어지는 것을 막기 위한 안전장치다.

### 손절 간격에 ATR을 사용하는 이유

고정 손절은 변동성이 커졌을 때 정상적인 가격 흔들림에도 쉽게 청산될 수 있다. 1분봉과 5분봉 중 큰 ATR을 사용하면 단기 변동성과 조금 더 넓은 변동성을 함께 반영할 수 있다.

ATR의 3배를 사용하고 `$400~$700` 범위로 제한한 것은 너무 가까운 손절과 과도하게 큰 손실을 동시에 방지하기 위해서다.

### 1차 익절을 `$500~$600`으로 제한한 이유

1차 익절은 최소한 손절 간격과 비슷한 수준의 수익을 확보하도록 설계했다. 너무 가까우면 수수료 대비 수익이 작고, 너무 멀면 단타에서 체결 가능성이 낮아지므로 `$500~$600` 범위로 제한한다.

### 2차 익절을 `$800`로 설정한 이유

1차 익절보다 큰 추세가 이어질 때 추가 수익을 확보하기 위한 목표다. 단기 움직임은 TP1에서 대응하고, 강한 추세는 TP2까지 보유하는 구조다.

### 대기 주문을 2시간 뒤 재계산하는 이유

오래된 지정가는 현재 시장의 ATR, 거래량, MA와 맞지 않을 수 있다. 2시간 동안 체결되지 않으면 기존 주문을 취소하고 최신 지표로 진입가·손절가·익절가를 다시 계산해 낡은 주문이 계속 남는 것을 막는다.

### 더 유리한 가격으로만 갱신하는 이유

대기 중인 주문을 현재가 방향으로 계속 따라가면 결국 추격 진입이 된다. LONG은 더 낮은 가격, SHORT은 더 높은 가격으로만 갱신해 처음 계획보다 불리한 진입을 줄인다. 단, 강한 A등급 추세에서는 예외적으로 최신 가격을 따라갈 수 있다.

### 이 설정의 단점

- 조건 확인 과정에서 빠른 급등·급락 진입을 놓칠 수 있다.
- 거래량이 낮은 추세에서는 방향이 맞아도 주문이 생성되지 않을 수 있다.
- 지정가가 유리한 방향에 있어 미체결로 끝날 수 있다.
- ATR이 갑자기 커지면 진입가와 손절가가 평소보다 멀어질 수 있다.
- 현재 수치는 BTCUSDT 단타 기준이며 시장 상황에 따라 재조정이 필요하다.
