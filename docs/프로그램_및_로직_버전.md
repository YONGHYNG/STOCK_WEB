## 2. 전체 구성

```text
Bitget 공개·인증 API
        ↓
캔들 및 시장 데이터 수집
        ↓
멀티타임프레임 전략·지표·거래량 이벤트 분석
        ↓
리스크 필터 및 진입 타이밍 확인
        ↓
PAPER / LIVE 주문 실행
        ↓
SQLite 기록 + WebSocket 화면 갱신 + Gmail 알림
```

### 주요 디렉터리

| 경로 | 역할 |
|---|---|
| `api/` | FastAPI 라우터, 요청 스키마, 거래 제어 서비스, WebSocket |
| `backend/bitget/` | Bitget 공개·인증 API 클라이언트 |
| `backend/indicator/` | EMA, RSI, MACD, ATR 등 지표 |
| `backend/strategy/` | 멀티타임프레임 분석, 진입 타이밍, 백테스트, 거래량 전략 |
| `backend/risk/` | 리스크 설정, 연속 손실, 손절 관리 |
| `backend/order/` | 주문 수량, PAPER 거래, 주문·포지션 관리 |
| `backend/notifications/` | Gmail 설정 및 거래 이벤트 메일 |
| `frontend/src/` | React 대시보드 화면과 API 클라이언트 |
| `data/` | SQLite DB와 로컬 설정 파일 |
| `frontend/tests/` | 전략·주문·복구·메일 단위 테스트 |

## 3. 실행 프로그램

### 백엔드 API

- 진입점: `python -m api.main`
- 기본 주소: `http://127.0.0.1:8000`
- 역할: 분석 루프, 주문 제어, DB 저장, REST API, WebSocket

### React 웹 대시보드

- 개발: `npm run dev`
- 빌드: `npm run build`
- 역할: 상태, 시그널, 포지션, 손익, 거래 이력과 설정 표시

### Electron 데스크톱

- 실행: `npm run desktop`
- Windows 빌드: `npm run build:windows`
- 역할: 웹 대시보드를 Windows 데스크톱 앱으로 패키징

### Android

- 동기화: `npm run android:sync`
- 빌드: `npm run build:android`
- 역할: Capacitor를 이용한 Android 패키징

## 5. 현재 거래 로직 버전 설명

### 시장 데이터

- 분석 대상 시간봉: `1m`, `5m`, `15m`, `30m`, `1H`, `4H`, `6H`, `1D`
- 시간봉별 최근 660개 확정 캔들 유지
- 기본 판단 시간봉: `5m`
- 기본 갱신 간격: 15초

### 전략 엔진

- 멀티타임프레임 방향 종합
- 추세 지속, RSI 전환, 거래량 돌파·재테스트, 횡보 반전, 중립 모멘텀
- 거래량 급증 이벤트 진단
- 진입 등급과 차단 사유 생성

### PAPER 주문

- 초기 잔액 기본값: $100
- 레버리지: 20배
- 진입 비중: 50% + 25% + 25%
- 추가 진입 간격: 단계별 $250
- PAPER 3단계 최소 손절 폭: $750
- 추가 체결 후 실제 평균단가 기준으로 TP1·TP2·SL 재계산

### 거래 비용과 시장 보호

- 일반 스프레드 기준: 0.03%
- 주의 스프레드 기준: 0.07%
- Maker 수수료 가정: 0.03%
- Taker 수수료 가정: 0.06%
- 진입 계획가 대비 최대 허용 이탈: 0.60%

### 알림

- Gmail SMTP SSL, 포트 465
- 예상 진입, 최초 체결, 추가 진입, 익절, 손절과 청산 이벤트 지원
- 추가 진입 메일에 현재 평균단가, SL, TP1, TP2 포함

## 6. 설정 파일

| 파일 | 내용 |
|---|---|
| `backend/config.py` | 심볼, 시간봉, DB 경로, Bitget 주소, 수수료·스프레드 상수 |
| `data/risk_settings.json` | 진입 임계값, 손실 제한, 재진입 시간, TP·SL 범위 |
| `data/gmail_config.json` | Gmail 발신 설정. 비밀번호가 포함될 수 있으므로 외부 공유 금지 |
| `data/trading.db` | 캔들, 신호, 거래, 계좌와 복구 상태 |
| `frontend/package.json` | 프론트엔드와 패키징 버전 범위 |
| `requirements.txt` | Python 패키지 최소 버전 |

## 7. 버전 관리 시 함께 확인할 항목

로직 변경 시 최소한 다음을 함께 기록하는 것이 좋다.

1. 애플리케이션 또는 전략 버전 번호
2. 변경한 진입·익절·손절 상수
3. DB 스키마 변경 여부
4. 테스트 통과 개수와 주요 백테스트 결과
5. PAPER 라운드 시작 거래 ID
6. Python·Node 잠금 파일 변경 여부
