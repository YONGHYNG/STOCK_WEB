# 타점 개선 내역 — 2026-09-14

## 적용 범위

- 일반 자동 진입: 완성된 5분봉으로 눌림/반등 후 재출발 또는 구조 돌파 후 별도 재테스트 확인.
- 롱은 직전 봉 고점 위, 숏은 직전 봉 저점 아래 종가와 같은 방향 캔들 몸통을 요구.
- EMA20/VWAP 접촉 허용 거리는 0.20 ATR, 확인 종가와 기준선 거리는 최대 0.75 ATR.
- 확인 이후 현재 가격이 유리한 방향으로 0.25 ATR보다 멀어지면 추격 주문 보류.
- 확인봉은 마감 후 다음 5분 동안만 유효. 지지/저항 구조 이탈 또는 최근 20개 봉의 누락·중복도 보류.
- 상위 시간봉 반대 방향은 단순 EMA 접촉 대신 구조 돌파 → 별도 재테스트 → 재출발을 요구.
  기존 일반 진입의 상위 시간봉 반대 방향 하드 차단은 완화하지 않음.
- 가장 최근 실제 PAPER/LIVE 청산이 같은 방향의 이익 거래라면 청산 뒤 시작된 새 구조만 재진입 허용.
  조회는 DB 청산 시각순이며 PLAN과 다른 매매 모드를 제외하므로 재시작에도 적용.
- 일반 대기 주문은 최신 타점 및 기존 확인봉의 만료·무효 여부를 다시 검사해 취소.
- 정시 세션은 마감 전 타점 확인을 요구하되, 기존 마감 1분 전 강제 진입은 유지.
  미충족 타점의 마감 예외는 거래 사유에 `DEADLINE_OVERRIDE`와 미충족 이유를 기록.
- 정시 체결 가격은 확인 시점 현재가로 계획을 다시 계산. 미체결 EMA 가격을 체결 가격처럼 사용하지 않음.
- 20배 수량 계산, 정시 세션, 분할 비율, 손절·익절 배수는 변경하지 않음.
- 정의되지 않은 `previous_close`로 눌림·재테스트 분석이 실패하던 기존 오류 수정.

```powershell

python -m unittest discover -s tests -q
python scripts/replay_entry_timing.py
python scripts/replay_entry_timing.py --start 2026-08-01 --output reports/entry-timing-august-september.json
```

## 기록 재생 결과의 한계

9/11~14 KST에 진입한 PAPER 9건(미청산 1건 포함)은 원래 진입 시각·저장 가격을
그대로 새 검사에 넣으면 모두 대기 판정이다. 8/1~9/14의 71건도 모두 대기 판정이다.
이는 기존 수익 거래도 제외한다는 뜻이며, 손실 회피율이나 수익 개선의 증거가 아니다.

별도로 9/11~14 구간의 완성 5분봉을 검사했을 때 타점 단독 후보는 롱 5개·숏 3개였다.
상위 시간봉과 기존 전략 신호를 모두 적용한 실제 주문 수는 이보다 적을 수 있다.
기본 임계값은 수익 최적화로 검증한 값이 아니며 진입 빈도를 상당히 줄인다.

저장 진입가는 분할 체결 후 평균가일 수 있고, 당시 실시간 데이터 수신 시점은 재현하지 않았다.
원래 거래 대신 언제 새 주문이 체결되는지, 정시 마감 예외가 어떤 손익을 만드는지까지
시뮬레이션한 전체 전략 백테스트는 아니다. 강제 진입 예외가 유지되어 실제 손실은 계속 발생할 수 있다.

운영 DB의 과거 거래/설정은 수정하지 않았으며, 실행 중인 서버를 재시작하지 않았다.
실행 프로세스 적용에는 백엔드 코드 재로딩이 필요하다.
